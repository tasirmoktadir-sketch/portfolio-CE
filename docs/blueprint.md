# **App Name**: Cinematic Edge - Mohtasim Moktadir Tasir

## Core Features:

- Video Gallery: Showcase embedded video projects in a visually appealing gallery.
- About Me Section: An 'About Me' page displaying bio and skills.
- Contact Form: Simple contact form for inquiries.

## Style Guidelines:

- Primary color: Black (#000000) for a professional, sleek aesthetic.
- Background color: Off-white (#FAFAFA) to provide contrast against the black and ensure readability.
- Accent color: Charcoal grey (#333333) for subtle visual interest and highlights.
- Secondary accent color: Beige (#F5F5DC) for a touch of warmth and sophistication.
- Body and headline font: 'Inter', a sans-serif font offering a clean and modern aesthetic suitable for both headers and body text.
- Minimalist icons to represent different video categories or project types.
- Clean and structured layout for easy navigation.
- Subtle transitions and animations for a professional user experience.
